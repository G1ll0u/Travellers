# Travellers b0.1.4 - formations
**Config will be reset, a backup will be created in `minecraft/config/travellers/`**
**VERSION NUMEROTATION CHANGED FROM 1.x.x to 0.x.x for meaningfulness
### Added 

- **Added** Formations GUI
  - Allows you to set different formation styles and settings
  - You can modify formation settings pre-leader
  - Should work great on cave/tunnels (not too big groups, depends on circumstances, may stay on surface if group is too big)

- **Added** Henchman markers
  - Allows you to change worker colors / team clothes style
  - Per-player colors
  - Leader differentiation (has a layer on the head)

So you can now differentiate your henchmen and other people ones.

- **Added** Henchman offscreen simulation
  - Now every henchman is virtualized if not on-screen
  - No more chunks loaded when worker is offscreen
The moment a henchman reaches view distance frontier, he despawns and start simulating his movement until it reaches view distance again.

### Changed

- **Changed** `/travellerChunks` command to show simulated henchmen (it's a debug command, not meant to be used in survival)
- **Disabled temporarily** dog spawns

### Fixed

- **Fixed** some GUIs
